Retail Orders Data Quality Analysis

Project Overview

This project focuses on analyzing retail order data and identifying data quality issues using Microsoft Excel.

The main objective is to examine raw retail order data, identify inconsistencies, organize working data, and define important business KPIs.

Tools Used

- Microsoft Excel
- Excel Tables
- Data Cleaning
- Data Quality Analysis
- KPI Documentation

Project Worksheets

1. Retail Orders Raw Data – Original retail order dataset.
2. Retail Data Dictionary – Dataset column definitions.
3. Working Data – Working sheet for data checking and cleaning.
4. Data Quality Report – Identified data quality issues.
5. KPI Dictionary – Business KPI definitions and formulas.

Data Quality Issues Identified

- Duplicate Order IDs
- Missing Values
- Invalid Dates
- Negative Quantity
- Invalid Discount
- Invalid Text
- Inconsistent Case
- Inconsistent Date Format

Key Performance Indicators (KPIs)

- Total Orders
- Paid Orders
- Pending Orders
- Failed Orders
- Refunded Orders
- Units Sold
- Paid Revenue
- Average Order Value

Project Objective

To improve data quality, maintain consistency, and prepare reliable data for business analysis and reporting.
